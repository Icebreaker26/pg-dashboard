# Ejercicio de ventas y Pareto

Notebook del ejercicio "¿Vender más significa ganar más?" (tienda Conecta), completado y ejecutado.

## Cómo usarlo

**Opción 1: Google Colab**
1. Entra a [colab.research.google.com](https://colab.research.google.com).
2. Sube el archivo `Ejercicio_ventas_y_Pareto.ipynb`.
3. Ejecuta las celdas en orden con `Shift + Enter`.

**Opción 2: Jupyter local**
1. Instala las librerías necesarias:
   ```
   pip install pandas numpy seaborn matplotlib jupyter
   ```
2. Abre el notebook:
   ```
   jupyter notebook Ejercicio_ventas_y_Pareto.ipynb
   ```
3. Ejecuta las celdas en orden con `Shift + Enter`.

Los datos de ventas están incluidos dentro del notebook (no hay que descargar nada aparte).
